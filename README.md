<a id="chapter-0"></a>
## Описание проекта

WiFiPlate - простая WiFi табличка на дверь на основе Wemos Mini и светодиодных матриц MAX7219.

-

<a id="chapter-1"></a>
## Возможности

- Вывод текста на матрицу через веб-интерфейс
- Быстрый выбор предустановленных статусов:
  - Busy (Занят)
  - Away (Вышел)
  - Available (Доступен)
- Настройка Wi-Fi через встроенный веб-интерфейс
- Управление через мобильное приложение Gyver Settings
- Совместимость с Arduino IDE и PlatformIO

## Установка

### PlatformIO (рекомендуется)

1. Клонируйте репозиторий
2. Откройте проект в VS Code с расширением PlatformIO
3. Залейте прошивку:

```bash
pio run -t upload
```

### Arduino IDE

1. Скопируйте код из файла `src/main.cpp`
2. Установите библиотеки через менеджер библиотек
3. Выберите плату и загрузите прошивку

<a id="chapter-6"></a>
## Обновление через OTA

Готовые прошивки в формате `.bin` доступны в разделе [Releases](https://github.com/DarkHolocron/WiFiPlate/releases) на GitHub.

Для обновления прошивки :

1. Откройте веб-интерфейс таблички
2. Нажмите на значок "три полоски" в правом верхнем углу
3. Выберите пункт "OTA"
4. Нажмите "Выберите файл" и укажите скачанный файл прошивки (.bin)
5. После выбора файла появится всплывающее окно с вопросом об обновлении прошивки. Нажмите "ОК" и дождитесь окончания процесса

<a id="chapter-7"></a>
## Первое включение

При первом включении устройство создает собственную Wi-Fi сеть с именем "WiFiPlate". Для настройки:

1. Подключитесь к сети "WiFiPlate" со своего телефона или компьютера
2. Откройте браузер и перейдите по адресу `192.168.4.1`
3. В появившемся интерфейсе введите название вашей Wi-Fi сети (SSID) и пароль
4. Нажмите кнопку "Connect"
5. После успешного подключения устройство перезагрузится и подключится к вашей Wi-Fi сети. IP-адрес таблички автоматически выведется в Serial-порт

<a id="chapter-8"></a>
## Использование

### Веб-интерфейс

Для доступа к веб-интерфейсу используйте IP-адрес, полученный в Serial-порте при подключении, и введите его в браузере.

### Мобильные приложения

После настройки Wi-Fi подключения, вы можете управлять табличкой через приложения. Приложения автоматически найдут устройство в локальной сети, без необходимости вводить IP-адрес вручную:

- **iOS**: [Gyver Settings](https://apps.apple.com/us/app/gyver-settings/id6751504764)
- **Android**: [Settings-discover](https://github.com/GyverLibs/Settings-discover)
- **Windows**: [Remote Settings Manager](https://github.com/TonTon-Macout/Remote-Settings-Manager)

<a id="chapter-9"></a>
## Управление

### Поле ввода текста

- Введите любой текст в поле input
- Нажмите кнопку "Send" для вывода текста на табличку

### Кнопки быстрого доступа

- **Busy** - отображает статус "Busy" (Занят)
- **Away** - отображает статус "Away" (Вышел)
- **Available** - отображает статус "Available" (Доступен)
- **Clear** - очищает матрицу 

### Настройки

- **Bright** - слайдер регулировки яркости матрицы (от 0 до 15)
